# musteri-veri-analizi
Python kullanılarak e-ticaret satış verileri analiz edilmiştir. Proje kapsamında veri temizleme, keşifsel veri analizi (EDA), satış performansı inceleme, RFM yöntemiyle müşteri segmentasyonu ve Matplotlib &amp; Seaborn ile veri görselleştirme çalışmaları gerçekleştirilmiştir.
